# Método SEMMA

SEMMA es una metodología para la minería de datos y el aprendizaje automático desarrollada por el SAS Institute, diseñada para extraer patrones y conocimiento de grandes volúmenes de datos. Se estructura en cinco fases secuenciales e iterativas:

- Sample (Muestreo): Selección de un subconjunto representativo de datos para reducir el volumen de procesamiento sin perder información significativa.
- Explore (Exploración): Análisis de los datos mediante visualización y estadística descriptiva para identificar tendencias, correlaciones y anomalías.
- Modify (Modificación): Limpieza, transformación y creación de variables para optimizar los datos antes del modelado.
- Model (Modelado): Aplicación de técnicas como árboles de decisión, redes neuronales o regresión para crear modelos predictivos.
- Assess (Evaluación): Verificación de la precisión, confiabilidad y utilidad del modelo seleccionado mediante métricas de rendimiento.

Aunque originalmente vinculada al software SAS Enterprise Miner, SEMMA es adaptable a otros entornos. Su principal limitación frente a metodologías como CRISP-DM es que se centra casi exclusivamente en las tareas técnicas de modelado, omitiendo la fase de comprensión de los objetivos comerciales.
